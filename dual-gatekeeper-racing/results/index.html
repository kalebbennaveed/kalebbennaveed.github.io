Where the informative trajectory is implemented

dual_gtk_drs_racing/gatekeeper.py, Gatekeeper.replan (line 83), calls self.informative.optimize with fixed γ = 2, initialized from the nominal control sequence. dual_gtk_drs_racing/mppi.py, objective (line 70), accumulates the noise-scaled friction-regressor Gramian and subtracts γ log(1 + I); MPPI.optimize returns the optimized controls and predicted states.

Gatekeeper.candidate evaluates each prefix; belief.py:predicted_quantized_width predicts contraction. Gatekeeper.replan then applies paired safety, exploration-budget and discounted-contraction selection. The README links directly to these files in the implementation repository.
