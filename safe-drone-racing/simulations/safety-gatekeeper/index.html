What is shared, and what changes

Shared system

The same 12-state rigid-body base model, neural-controller checkpoint, command limits, 20 Hz controller, 1 ms ground-truth integration, course, body size and MPPI settings are used within each environment. The model and controller remain fixed during each recording.

The DevQuad v2 visual uses the lab’s CAD components and documented motor spacing, with 5-inch tri-blade propellers. Its 0.19 m collision sphere encloses the visual at every rotor angle. The visual does not make these dynamics a calibrated hardware model.

Dynamics comparison

Baseline 1 has no residual in either the prediction model or ground-truth simulator. Baseline 2 and Method 1 share the same true velocity-dependent residual and its learned approximation. Their mismatch is the difference between those functions, not a change in the low-level controller.

Method 1 verification

Each of six candidates lasts 2.5 seconds, with switching times 2, 1.5, 1, 0.5, 0.2 and 0 seconds. The whole-state flowpipe accounts for the neural controller and the residual-error bound. Position sets plus the physical drone size must avoid gates, supports, room obstacles, floor and ceiling.

A geometry failure does not truncate the tube. If propagation itself fails, only its established prefix is drawn; the remaining reference is gray. Floating-point arithmetic is not formally certified, and finite-horizon checks do not prove indefinite safety.
