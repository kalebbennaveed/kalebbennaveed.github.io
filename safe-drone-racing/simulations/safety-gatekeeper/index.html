CURRENT IMPLEMENTATION

How the flight is generated

Base modelKnown equations for motion, orientation, thrust response and body-rate response.

Prediction modelBase model + a neural network's learned acceleration correction. Used to predict future states.

Ground-truth simulatorThe simulated drone that receives the applied commands. The mismatch run adds hidden drag and acceleration bias.

  1. MPPI generates the nominal trajectory.

    It tries command sequences, predicts their motion with the prediction model, and scores forward progress, course error and control effort. Its output is a two-second sequence of reference states and thrust/body-rate commands.

  2. With Gatekeeper: simulate a candidate.

    Starting at the measured state, simulate the neural tracker following the nominal reference until a chosen switch time. Then simulate the backup controller, which follows the course centerline at 2 m/s. The prediction model produces every future state. The first candidate has zero nominal duration: backup starts immediately.

  3. Check the candidate, then keep an accepted reference.

    Propagate model error and measurement error along the candidate. Check the resulting position bounds against the course, then check terminal position, velocity and tilt. An accepted candidate becomes the committed reference. If a later candidate fails, the previous commitment continues moving along its backup reference.

  4. The neural tracker generates applied commands.

    It receives the measured state, reference state/command and previous command. It outputs thrust and body rates, subject to magnitude and change-rate limits. It tracks the whole committed reference, including the backup portion. The geometric backup generates that reference; it does not replace the executing neural tracker.

Without Gatekeeper: MPPI reference → neural tracker → ground-truth simulator. No candidate, commitment or backup switch is used. These are the two moving runs compared below.

Dynamics learning and controller learning

The dynamics ensemble averages three networks to predict an acceleration correction from measured state changes and applied commands. The control-policy network learns how to track a reference. When the dynamics model changes, policy training simulates tracking with that model and updates the controller weights by backpropagation through time. No ATS is used. In a Gatekeeper run, a policy update enters execution only with an accepted candidate; in an unfiltered run, it enters after the training validation check.

The current Gatekeeper tube is a Jacobian approximation. Its nonlinear enclosure and the moving backup's invariant set have not been established. The current neural backup-only initialization fails its terminal check; it is shown separately from the two unfiltered flight recordings. The ground-truth simulator is a 14-state body-rate/actuator model, not a rotor-resolved high-fidelity simulator.
